# Projeto SQL — Empresas

Projeto acadêmico desenvolvido durante o curso de **Ciência da Computação**.

## 📌 Sobre o projeto

Este projeto apresenta a modelagem de um banco de dados para gerenciamento de informações relacionadas a empresas, departamentos e funcionários.

O projeto foi desenvolvido utilizando **SQL**, com criação de tabelas, relacionamentos, inserção de dados e consultas.

## 🗄️ Estrutura do banco

O banco de dados possui as seguintes entidades:

* **Escritório**
* **Departamento**
* **Funcionário**

Também foram utilizados relacionamentos entre as tabelas por meio de **chaves primárias e estrangeiras**.

## 💻 Conceitos utilizados

* Criação de tabelas com `CREATE TABLE`
* Inserção de dados com `INSERT`
* Consultas com `SELECT`
* Filtros com `WHERE`
* Intervalos com `BETWEEN`
* Busca com `LIKE`
* Ordenação com `ORDER BY`
* Relacionamentos com `FOREIGN KEY`
* Consultas utilizando `INNER JOIN`
* Modelagem de banco de dados

## 🎓 Contexto acadêmico

Projeto desenvolvido como parte da formação em **Ciência da Computação**, com foco em modelagem e manipulação de bancos de dados relacionais.
